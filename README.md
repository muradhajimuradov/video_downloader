# YouTube Video Downloader для Android (Flutter)

Мобильное приложение для Android на Flutter / Dart для скачивания видео и аудио с YouTube, созданное как полноценный аналог десктопного Python-приложения.

---

## ✨ Возможности и отличия

- **Фирменный дизайн в стиле YouTube (Material 3 Dark Theme)**:
  - Тёмная палитра (`#101015`, `#191922`, `#20202C`) с акцентным цветом YouTube Red (`#FF0033`).
  - Современные скругленные карточки, плавная прокрутка, контрастная типографика.
- **Интеллектуальная работа с ссылками**:
  - Поддержка всех типов ссылок YouTube: стандартные `youtube.com/watch?v=...`, короткие `youtu.be/...`, Shorts `youtube.com/shorts/...`, мобильные `m.youtube.com/...` и YouTube Music `music.youtube.com/...`.
  - Автоматическая проверка буфера обмена при открытии приложения.
  - Кнопка быстрой вставки из буфера обмена и очистки поля.
- **Детальная информация о видео**:
  - Обложка (Thumbnail) высокого разрешения с бейджем длительности.
  - Название видео и канал/автор.
- **Гибкий выбор качества и формата**:
  - 🔥 **Быстрое скачивание (Muxed HD 720p / 360p)**: готовый объединенный видео+аудио поток, скачивается мгновенно без перекодирования.
  - **Высокое разрешение (1080p Full HD, 1440p 2K, 2160p 4K, 60fps)**: скачивание чистого видеопотока и лучшей звуковой дорожки с автоматическим слиянием в единый `.mp4` через FFmpeg.
  - 🎵 **Только аудио (M4A / AAC)**: оригинальная звуковая дорожка максимального качества без сжатия.
  - 🎵 **Только аудио (MP3 320 kbps)**: конвертация через встроенный FFmpeg для максимальной совместимости с любыми плеерами и магнитолами.
  - Отображение примерного размера файла (~МБ) и частоты кадров (fps) для каждого варианта.
- **Прогресс загрузки в реальном времени**:
  - Анимированный прогресс-бар с точным процентом.
  - Скорость загрузки (МБ/с, КБ/с).
  - Скачанный объем и общий вес файла.
  - Расчет оставшегося времени (ETA).
  - Информативные статусы этапов (загрузка потока, конвертация/слияние через FFmpeg, завершение).
  - Возможность безопасной отмены загрузки в любой момент.
- **Интеграция с хранилищем Android**:
  - Сохранение напрямую в системную папку `Загрузки` (`/storage/emulated/0/Download/YouTubeDownloader`).
  - Файлы сразу видны в стандартном проводнике ("Файлы") и системной галерее.
  - Корректная поддержка Scoped Storage и разрешений для Android 10, 11, 12, 13, 14+.
- **История загрузок**:
  - Удобный нижний экран (Bottom Sheet) с историей скачанных файлов.
  - Кнопка "Открыть файл" в стандартном медиаплеере устройства.
  - Кнопка "Поделиться" через системный диалог Android.

## 🛠 Технологический стек

- **Flutter 3.x / Dart 3.x**
- **youtube_explode_dart**: высокопроизводительный клиент для извлечения метаданных и медиапотоков YouTube без необходимости в API-ключах.
- **ffmpeg_kit_flutter_new**: нативная интеграция FFmpeg на Android для мультиплексирования раздельных видео+аудио потоков (1080p, 1440p, 4K) и кодирования аудио в MP3 320 kbps.
- **path_provider** & **permission_handler**: управление путями и разрешениями Android.
- **open_filex**: открытие скачанных видео/аудио в стандартных приложениях Android.
- **share_plus**: отправка и публикация файлов через системное меню Android.
- **shared_preferences**: хранение локальной истории скачиваний.

## 📁 Структура проекта

```
android youtube downloader/
├── android/                             # Нативный Android-проект
│   └── app/
│       ├── build.gradle.kts             # minSdk = 24, compileSdk
│       └── src/main/AndroidManifest.xml # Разрешения на интернет и хранилище
├── lib/
│   ├── main.dart                        # Точка входа и главный экран HomeScreen
│   ├── models/
│   │   └── video_model.dart             # Модели данных (видео, форматы, прогресс, история)
│   ├── services/
│   │   ├── download_service.dart        # Логика скачивания потоков и обработка через FFmpeg
│   │   ├── history_service.dart         # Управление историей загрузок (SharedPreferences)
│   │   ├── storage_service.dart         # Доступ к папке Downloads и проверка разрешений
│   │   └── youtube_service.dart         # Парсинг URL и получение метаданных через YoutubeExplode
│   ├── theme/
│   │   └── app_theme.dart               # Тёмная Material 3 тема и палитра YouTube
│   └── widgets/
│       ├── download_history_sheet.dart  # Экран истории загрузок
│       ├── download_progress_card.dart  # Карточка с прогрессом, скоростью, ETA и кнопками
│       ├── header_widget.dart           # Шапка со статусом FFmpeg и кнопкой истории
│       ├── quality_selector_card.dart   # Селектор качеств и форматов
│       ├── storage_card.dart            # Отображение папки сохранения
│       ├── url_input_card.dart          # Поле ввода URL с кнопкой вставки
│       └── video_info_card.dart         # Карточка видео (превью, название, длительность)
├── pubspec.yaml                         # Зависимости проекта
└── README.md
```

## 🚀 Запуск и сборка

### Запуск в режиме отладки (на подключенном Android-смартфоне или эмуляторе):

```bash
flutter run
```

### Сборка релизного APK:

```bash
flutter build apk --release
```

Готовый файл APK будет сохранен по пути:
`build/app/outputs/flutter-apk/app-release.apk`
